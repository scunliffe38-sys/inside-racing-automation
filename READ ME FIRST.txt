INSIDE RACING — the complete repository contents
Rebuilt 18 September 2026, with Gotham Narrow Bold
================================================

This is everything the repository holds, not just the changed files: every
page, every parser, the fonts, the artwork, the sample inputs, the bake and
the notes. Use it when you want the clone brought wholly into line rather
than patched.

WHAT TO DO
----------
1. Unzip this folder somewhere outside your clone.
2. Open your clone in Explorer (GitHub Desktop: Ctrl+Shift+F).
3. Copy everything EXCEPT "READ ME FIRST.txt" into the clone, keeping the
   folder structure. Overwrite when asked.
4. GitHub Desktop's Changes tab will list only the files that actually
   differ — most of these are already identical to what is pushed.
5. Commit to main, then Push origin.

Nothing is deleted by copying, so a file that exists in the clone but not
here stays put. If you would rather start clean, delete the clone's contents
first (leaving the hidden .git folder alone) and then copy this in.
