Advertising artwork for this edition.

Drop supplied artwork in this folder, then type its file name in the "Artwork file name" column
of "inputs/Ad Placements.xlsx" next to the page number it runs on.

  - PNG or JPG only. Export a PDF ad to JPG at 300dpi first.
  - Name the file plainly: sportsbet-fullpage.png, not final_v3 (2).png.
  - A bare filename here is found automatically. House artwork already in the
    project (assets/ads/, assets/photos/) is found the same way, so the three
    standing house ads need no file dropped in this folder.

Positions and the artwork size each wants are on the "How to fill this in" tab
of the workbook. A position left out falls back to the house ad that normally
runs there, so a missed row never leaves a hole.
