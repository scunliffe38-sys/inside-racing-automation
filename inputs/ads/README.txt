Advertising artwork for this edition.

Drop supplied artwork in this folder, then name the file in the artwork column
of "inputs/Ad Placements.csv" against the slot it should run in.

  - PNG, JPG or PDF-flattened PNG. Native resolution, no downsampling.
  - Name the file plainly: sportsbet-fullpage.png, not final_v3 (2).png.
  - A bare filename here is found automatically. House artwork already in the
    project (assets/ads/, assets/photos/) is found the same way, so the three
    standing house ads need no file dropped in this folder.

Slot ids, what they are and the artwork size each wants, are listed in the
placement report the run produces. Every slot left out of the CSV falls back to
the house ad that normally runs there, so a missed row never leaves a hole.
