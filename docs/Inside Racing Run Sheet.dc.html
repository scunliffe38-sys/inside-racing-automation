Running a month
1. Replace the inputs. Same filenames every month. The three tab-separated exports come out of the reporting tool as UTF-16 and are read as-is — no conversion step.
2. Open each page and read the console. Row counts, missing fields, values in the wrong column and figures that don’t add up are all reported by name and row number.
3. Check the page furniture. Edition Settings.xlsx carries the edition name, the wins-as-at date, the two standing paragraphs and the Yes/No switches for the Jumps Program and Picnic Racing. Page numbers are not settings — they are worked out from the running order and this month’s section lengths, so open the pages in order and the folios settle, then export to PDF. A * above means that section has not been opened yet and is showing its standing extent.
